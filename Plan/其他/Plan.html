📋 项目概述

这是一个前后端分离的 AI 聊天网站，调用 DeepSeek API（兼容 OpenAI 接口）实现自然语言对话。 采用现代 Web 技术栈，支持多轮对话记忆、流式打字机效果、用户注册登录 以及历史记录持久化。 适合作为学习全栈开发、AI 应用集成的实战项目，也可直接部署上线提供给朋友使用。

浏览器 (Vue 3) → Flask API → DeepSeek 模型

核心功能：

  • ✅ 流式对话 —— 打字机逐字输出，体验极佳
  • ✅ 多轮记忆 —— 上下文连贯，对话不“失忆”
  • ✅ 用户系统 —— 注册、登录、JWT 鉴权
  • ✅ 历史记录 —— 刷新不丢失，可回顾过往对话
  • ✅ 响应式界面 —— 适配手机和桌面端
  • ✅ 一键部署 —— 前后端均可免费托管到云平台

后端流式聊天接口 (Flask)

@chat_bp.route('/api/chat', methods=['POST'])
@jwt_required()
def chat_stream():
    data = request.get_json()
    user_msg = data['message']
    history = get_chat_history(current_user_id)
    history.append({"role": "user", "content": user_msg})
    
    def generate():
        stream = client.chat.completions.create(
            model="deepseek-v4-pro",
            messages=history,
            stream=True
        )
        for chunk in stream:
            delta = chunk.choices[0].delta
            if delta.content:
                yield f"data: {delta.content}\n\n"
        yield "data: [DONE]\n\n"
    
    return Response(generate(), mimetype='text/event-stream')

前端 EventSource 接收流

const eventSource = new EventSource('/api/chat');
eventSource.onmessage = (event) => {
  if (event.data === '[DONE]') {
    eventSource.close();
    return;
  }
  assistantReply.value += event.data;  // 逐字拼接显示
};

🗺️ 推荐开发步骤 (分阶段实现)

  1. 环境搭建 – 初始化 Vite + Vue 3 项目，Flask 项目，安装依赖，配置代理解决跨域
  2. 基础对话 – 后端 `/api/chat` 接口返回完整回复，前端用 Axios 调用并显示
  3. 流式输出 – Flask 改用 SSE，前端使用 EventSource 实现打字机效果
  4. 对话记忆 – 前端维护 messages 列表传入后端，后端保存历史到数据库（可按用户隔离）
  5. 用户系统 – 创建 User 表，实现注册、登录、JWT 保护接口，前端路由守卫
  6. 界面美化 – Naive UI 组件替换原始表单，添加加载状态、错误提示、滚动自动底部
  7. 部署上线 – 前端打包部署 Vercel，后端用 Gunicorn + Railway/Render，配置环境变量与 HTTPS
  8. 额外优化 – Docker 容器化、日志、错误监控、单元测试、TypeScript 迁移等
💡 建议： 每完成一个阶段就 commit 代码，方便回滚与迭代。全程可使用 AI 编程助手加速开发。
