## 九、TCP 与 HTTP 协议底层

| 知识点 | 熟练度 |
|--------|--------|
| TCP 三次握手（SYN → SYN-ACK → ACK） | 理解 |
| TCP 四次挥手（FIN → ACK → FIN → ACK）——双向关闭，不能合并 | 理解 |
| 少了握手 → 连接建立失败；少了挥手 → 半开连接，资源不回收 | 理解 |
| HTTP 响应结构（状态行 + 响应头 + 空行 + 响应体） | 熟练 |
| `Content-Length`（定长响应）vs `Transfer-Encoding: chunked`（流式响应） | 理解 |
| `Content-Length` 被篡改 → 响应体截断 → JSON 解析失败 | 理解 |
| HTTPS 不仅加密响应体——也保护 `Content-Length` 等元数据完整性 | 了解 |
