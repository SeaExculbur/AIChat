## 一、浏览器事件系统

### 你在输入框敲了一个字母，发生了什么

键盘 → 电信号 → 操作系统 → 当前活跃程序（浏览器）→ 浏览器发现按键发生在 `<input>` 框里 → 触发一个通知："这个输入框的内容变了"。

### 事件（Event）

浏览器内部有一个永不退出的等待循环——和服务器 `while True: accept()` 一样。它在等用户对页面做任何事：按键、鼠标移动、点击、滚动。

| 用户动作 | 触发的事件 |
|---------|----------|
| 键盘按下 | `keydown` |
| 键盘松开 | `keyup` |
| 输入框内容变化 | `input` |
| 鼠标点击某个元素 | `click` |
| 鼠标移动 | `mousemove` |

**专业术语**：DOM 事件系统（DOM Event System）。DOM = Document Object Model，即"文档对象模型"——浏览器把 HTML 页面在内存里建成一棵节点树，树上每个节点都可以响应事件。

---

## 二、DOM 树

### 网页不是图片，是一棵树

浏览器读完 HTML 文件后，在内存里建一棵节点树：

```
文档根节点
  ├── <input type="text">    （输入框节点）
  ├── <button>发送</button>   （按钮节点）
  └── <div>                   （容器节点）
        ├── <p>消息1</p>       （段落节点）
        └── <p>消息2</p>       （段落节点）
```

每个 HTML 标签变成一个 JS 对象——你可以用代码读它的属性（`.value`、`.textContent`），改它的样式（`.style.color = 'red'`），甚至删掉它重新建。

### 没有 Vue 的世界

```js
// 找到输入框
const inputEle = document.querySelector('input')
// 找到按钮
const btn = document.querySelector('button')
// 找到消息容器
const msgBox = document.querySelector('.messages')

// 监听按钮点击
btn.addEventListener('click', () => {
    const text = inputEle.value          // 手动取值
    const newMsg = document.createElement('p')  // 手动建节点
    newMsg.textContent = text            // 手动填内容
    msgBox.appendChild(newMsg)           // 手动挂到树上
})
```

每做一个操作都要：找节点 → 读值 → 建新节点 → 填内容 → 挂树上。页面越复杂，这种代码越长。

## 三、Vue 的双向绑定（`v-model`）

Vue 把这套"找节点—读值—写值"的手动操作包了起来。

```html
<input v-model="message">
```

Vue 在背后自动做了两件事：

1. **输入框 → 变量**：监听 `input` 事件，自动拿 `.value`，写入 `message`
2. **变量 → 输入框**：`message` 变了，自动更新 `.value`

你不需要手动找节点、不需要手动绑定事件。你声明"这个输入框和这个变量是一体的"——Vue 维护同步。

**专业术语**：双向数据绑定（Two-way Data Binding）。

## 四、Vue 的响应式（Reactivity）

### 问题

```js
let username = 'Tom'
// 过一会
username = 'Jerry'
// 页面上写了 "欢迎，Tom" 的地方不会自动变成 "欢迎，Jerry"
```

### 解决

Vue 的 `ref()` 把一个普通变量套上追踪系统。之后只要这个变量变了，页面上所有用到它的地方**自动更新**。

**类比**：Excel 公式——改 A1 格子的值，所有引用了 A1 的公式格全部重算。

**专业术语**：响应式（Reactivity）。

---

## 五、事件绑定（`@click`）

```html
<button @click="sendMessage">发送</button>
```

翻译：当这个按钮被点击时，调用 `sendMessage` 这个函数。

**类比**：Flask 的 `@app.route("/api/chat")`——"当这个 URL 被访问时，调用这个函数"。`@click` 是同一个思想，只是映射的不是 URL，而是用户动作。

`@` 是 `v-on:` 的简写。`@click` = `v-on:click`。

**专业术语**：事件绑定 / 事件处理器（Event Binding / Event Handler）。

## 六、Axios — 前端版的 curl

### 等价关系

| | curl | Axios |
|---|---|---|
| HTTP 方法 | `-X POST` | `.post(url, body)` |
| 目标地址 | 完整 URL | 只需要路径（Vite 代理补齐域名） |
| 请求头 | `-H "Content-Type: application/json"` | Axios 自动加 |
| 请求体 | `-d '{"message":"你好"}'` | 传 JS 对象，自动转 JSON |
| Header 里的 token | `-H "Authorization: Bearer xxx"` | 拦截器自动加 |

### Axios 的底层

```
axios
  ↓ 底层调用
fetch()  （浏览器原生 API，现代浏览器都有）
  ↓ 底层调用
XMLHttpRequest  （十年前的技术，现在基本不用了）
  ↓ 底层调用
浏览器网络栈 → TCP → 服务器
```

**类比**：你后端用 `client.chat.completions.create()` 调 DeepSeek——底层是 `httpx`/`requests`，再底层是 `socket`。Axios 对前端 = OpenAI SDK 对后端。

**专业术语**：HTTP 客户端库（HTTP Client Library）。

## 七、Vite 代理

### 为什么需要代理

```
前端地址：localhost:5173（Vite dev server）
后端地址：localhost:5000（Flask）
```

浏览器的**同源策略**：两个地址的端口不同 → 浏览器判定跨域 → 禁止请求。

### 代理做了什么

```
浏览器 ── /api/chat ──► Vite (5173)   ← 浏览器只跟 5173 说话
                            │
                            │ Vite 收到后，自己转发
                            ▼
                        Flask (5000)   ← Flask 收到的请求来自 Vite，不是浏览器
                            │
                            │ 返回结果
                            ▼
浏览器 ◄── 响应 ──────── Vite (5173)   ← Vite 把结果还给浏览器
```

浏览器以为自己在跟 5173 一个人对话，Flask 以为请求是 Vite 发的。两边都不知道对方的存在——跨域问题不触发。

### 生产环境

`npm run build` 后，前端变成 `dist/` 下的静态文件，部署到 Vercel/Netlify。这时没有 Vite dev server 了，代理不存在。跨域靠 `CORS(app)`（后端 Flask-CORS 加的响应头）来解决。

## 八、完整链路（从前到后）

```
① 你敲键盘 '你好'，点"发送"
   → 键盘电信号 → 操作系统 → 浏览器

② 浏览器事件触发
   → input 事件更新了输入框的 value
   → v-model 自动把 value 写入 Vue 变量 message

③ 点击按钮
   → @click 触发 sendMessage 函数

④ sendMessage 函数内部
   → axios.post('/api/chat', { message: message的值 })
   → Axios 构造 HTTP 报文：
       POST /api/chat HTTP/1.1
       Content-Type: application/json
       Authorization: Bearer <token>
       {"message": "你好"}

⑤ 浏览器网络层
   → 在已建立的 TCP 连接上（和 localhost:5173）发送报文

⑥ Vite 代理
   → 收到 → 路径开头是 /api → 匹配代理规则
   → 新开 TCP 连接到 localhost:5000
   → 转发报文

⑦ Flask 收到请求
   → Werkzeug 解析 HTTP → 生成 environ 字典
   → Flask 路由匹配 → chat() 函数执行
   → （后续见 Plan/通信最底层逻辑链条.md）
```
